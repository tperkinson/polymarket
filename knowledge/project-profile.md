# Project Profile

## Purpose

Create a durable workspace where new conversations can quickly recover project context, understand available tools, and know what to verify before acting on Polymarket-related tasks.

## Working Assumptions

- The project is at the foundation stage.
- The current priority is knowledge continuity across conversations.
- Future deliverables may include scripts, data pipelines, research notes, dashboards, or trading/market-analysis utilities.
- No implementation stack has been selected yet.

## Boundaries

- Do not treat market or platform facts as stable unless this repository records a recent verified source.
- Do not give financial, legal, or eligibility advice as definitive guidance.
- Do not build automation that places trades, manages funds, or interacts with user accounts unless the user explicitly requests it and the safety/legal implications are clarified.

## Source Discipline

For current Polymarket facts, prefer primary sources such as:

- Polymarket documentation
- Polymarket API or official SDK references
- The live Polymarket UI/API for market-specific data
- Applicable legal or regulatory primary sources when eligibility/compliance is involved

Record source URLs, access dates, and what was learned in `knowledge/research-log.md`.
